> Đã được thay ngày 09/10/2026 bởi [document-standard-flexmix-manual](document-standard-flexmix-manual.md): thiết kế chuẩn giờ là FexMix_Munual. Phương pháp trong framework vẫn dùng.

Khi user yêu cầu viết một document mới, user muốn chất lượng phân tích và phong cách trình bày như các document HTML của `project1_server`, kể cả với đề tài khác, mà không cần mở lại các document mẫu. Dùng [framework tài liệu](../document-framework/START_HERE.md) trong secondbrain làm điểm vào: brief → nguồn thật → mô hình/luồng → dàn ý → HTML/CSS → kiểm. Giữ kiểu trình bày và kỷ luật nguồn/trạng thái; cấu trúc, độ dài và nội dung phải hợp đề tài/yêu cầu mới. Đây là yêu cầu user trong phiên hiện tại, không xác nhận mọi chi tiết do agent trích xuất trong framework.
