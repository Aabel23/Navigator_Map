Suy luận của agent từ một phiên, **chưa được user xác nhận**:

- Viết yêu cầu tiếng Việt, rất ngắn, đôi khi sai chính tả ("checck") → trả lời bằng tiếng Việt, tự suy ra phạm vi hợp lý từ repo thay vì hỏi nhiều. (Phiên này: một yêu cầu tiếng Anh-ish, phần còn lại tiếng Việt.)
- Muốn **nhìn thấy** tiến độ: thích trang live/tự cập nhật hơn báo cáo văn bản.
- Muốn quy tắc cho agent được **ghi xuống file md** trong repo để agent khác (Codex, Claude) làm theo.
- Làm việc với nhiều agent song song (Codex, Claude, "GPT Sol"), chia một khối một agent → cần cơ chế quan sát agent.
- Có thể đổi ý nhanh giữa chừng ("thôi khỏi" → "làm tiếp") → đừng phá bỏ công việc ngay khi có lệnh huỷ ngắn.
- Tự chạy lệnh trong terminal và dán lỗi lại → đưa lệnh copy-paste được, thông báo lỗi dễ hiểu.
- (09/10/2026) Với việc build + test có nhiều phần, user thích chạy Workflow nhiều agent ("ultracode được thì ngon", "nhiều subagent opus low") hơn một agent tuần tự; muốn bài toán được giải "chi tiết như giải bài tập" với số liệu thật của dự án.
- (10/10/2026) Khi cần đánh giá một thiết kế, user tự đặt cấu hình agent: mỗi agent một góc nhìn, có một agent "tờ giấy trắng" không đọc code để tránh thiên kiến, chạy ngầm, chỉ đánh giá không viết code, ghi rõ model/effort ("all opus med"). User hay phản biện kết luận bằng câu hỏi ngắn ("thì khác gì … mà không nên xoá?"), nên đừng bảo vệ kết luận chỉ vì nhiều agent cùng nói.
