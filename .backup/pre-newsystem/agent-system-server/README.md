# Server Agent System

This directory is the lightweight architecture guide for server-side development.

## Read order

1. `SYSTEM.md`
2. `TREE.md`
3. `CONNECTIONS.md`
4. `CODE_RULES.md`
5. Read the `connector.md` of the block being changed.

## Purpose

This system describes where server code belongs, how blocks connect, and the minimum rules agents must preserve.

Task-specific implementation details belong in the task prompt and the actual codebase, not here.
